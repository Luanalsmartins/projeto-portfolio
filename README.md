# Projeto Portfólio Pessoal

Este projeto é um **portfólio pessoal** desenvolvido para apresentar meus estudos, projetos e evolução como desenvolvedora front-end.  
Ele reúne informações sobre mim, minhas habilidades técnicas e alguns projetos práticos feitos durante minha jornada de aprendizado.

🔗 **Acesse o projeto online:**  
https://luanalsmartins.github.io/projeto-portfolio/

---

## 🎯 Objetivo do projeto

Criar um site pessoal para:

- Centralizar meus projetos em um único lugar  
- Praticar estruturação de páginas com HTML semântico  
- Trabalhar layout, responsividade e organização visual com CSS  
- Aplicar interações básicas com JavaScript  
- Simular um portfólio real para apresentação profissional  

---

## 🧩 Funcionalidades

- Página inicial com apresentação pessoal  
- Seção de projetos com descrição e links  
- Interações simples com JavaScript  
- Estrutura clara e organizada  
- Layout responsivo para diferentes tamanhos de tela  
- Navegação simples e intuitiva  

---

## 🛠️ Tecnologias utilizadas

- **HTML5**  
- **CSS3**  
- **JavaScript**  
- **Git**  
- **GitHub Pages**

---

## 📚 O que eu aprendi

- Estruturar um site completo usando HTML semântico  
- Organizar seções de um portfólio profissional  
- Trabalhar responsividade e alinhamento com CSS  
- Implementar interações básicas utilizando JavaScript  
- Publicar projetos utilizando o GitHub Pages  
- Melhorar a apresentação visual de projetos pessoais  

---

## 📌 Status do projeto

🚧 Em constante evolução  
O portfólio será atualizado conforme novos projetos forem desenvolvidos e novas tecnologias forem aprendidas.
